### Projet Bataille Navale - Devoir Maison

Cet ensemble de code est destiné à pouvoir émuler le jeu de la bataille navale en solo : on joue contre l'ordinateur.

Les bibliothèques Python nécessaires au bon fonctionnement du code se trouvent dans le fichier `requirements.txt`.
On pourra les installer, par exemple dans un environnement virtuel, avec la commande `python -m pip install -r requirements.txt`.

Enfin, pour exécuter le code et pouvoir enfin jouer, le fichier Python `main.py` est à exécuter.
